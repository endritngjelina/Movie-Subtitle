# Movie-Subtitle

A simple web-based project containing multiple movie subtitle HTML files. Each HTML file represents a separate movie subtitle page that can be opened directly in a web browser.

## 📌 Overview

The **Movie-Subtitle** project is a collection of HTML files designed to display movie subtitle content in a web browser.

The repository contains several numbered subtitle files:

- `movie subtitle 0.html`
- `movie subtitle 1.html`
- `movie subtitle 2.html`
- `movie subtitle 3.html`
- `movie subtitle 4.html`
- `movie subtitle 5.html`
- `movie subtitle 6.html`
- `movie subtitle 7.html`

These files can be viewed individually in a browser to explore the corresponding subtitle content.
